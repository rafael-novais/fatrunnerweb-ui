# Fatrunner

Fatrunner é uma aplicação Angular desenvolvida para ajudar pessoas a gerenciar sessões de treino, acompanhar metas de corrida e caminhada, e manter motivação diária por meio de visualizações claras, objetivos progressivos e indicadores de desempenho.

## Visão geral

O produto foi pensado para usuários que desejam melhorar disciplina, consistência e hábitos de atividade física, especialmente aqueles que enfrentam dificuldades para manter rotina e acompanhar evolução ao longo do tempo.

A plataforma centraliza:
- criação e gerenciamento de sessões de treino
- definição de metas diárias, semanais e mensais
- acompanhamento de progresso por tempo, distância e frequência
- indicadores visuais para reforçar motivação e engajamento
- experiência focada em simplicidade, clareza e ação diária

## Como executar

1. Instale as dependências:

```bash
npm install
```

2. Inicie a aplicação em modo de desenvolvimento:

```bash
npm start
```

3. Acesse no navegador:

```bash
http://localhost:4200
```
